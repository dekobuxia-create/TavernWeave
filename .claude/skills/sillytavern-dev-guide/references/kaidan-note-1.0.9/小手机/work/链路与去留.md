# 小手机通用化 · 链路与去留

对照源：`sources/1.0.9-内置图标`（r2）。拆出的可读稿在 `extracted/`。

## 1. 运行时三层

```text
酒馆宿主
  ├─ 助手脚本（host.bridge）
  │    挂载抽屉 · 读/写 MVU · 副 API · 发送/填入 · 点开局/选项/结算卡
  ├─ HUD（hud.script，内嵌在 HUD_SOURCE）
  │    主屏/Dock/小组件 · 13 个 App · 设置 · 本地 UI
  ├─ 正则套件（消息楼层）
  │    开局页 · 行动选项 · 变量结算卡
  └─ MVU Zod + 世界书变量条目
       15 根 stat_data · Schema 挂 __kaidanMvuSchema
```

数据不写进 HUD 的本地仓：外观、主屏布局、幽讯线程、搜索/新闻草稿、论坛帖、网购订单。  
数据写进当前楼层 `stat_data`：羁绊标签、删记录（鬼怪等）。

### kn / wc 是什么

这两个不是「手机系统功能」，是怪谈笔记自己的玩法 App，桌面图标分别叫 **Kaidan Note** 和 **世界调制**。

**`kn` = Kaidan Note（笔记本）**，四个页签：

1. **规则列表**：读 `怪谈笔记.法则`，按业力档上色，显示对象/怪谈内容/兑现人数/破译进度；槽位满了提示要撤旧法则。
2. **写新规则**：表单（对象、触发条件、怪谈内容、范围、时限）→ 填进输入框，文案是「凡写进来的,都会成为现实」。
3. **鬼怪捏造**：读/删 `怪谈笔记.鬼怪`，再写名称/形态/栖息地/传闻/危害等级，同样写入输入框。
4. **处刑档案**：读 `处刑档案` 总处刑数、死亡计数饼图、鬼怪处刑。

**`wc` = 世界调制**，一页：

- 顶上显示 `权限.当期修正`
- 折叠块 **后宫空间**（开通状态、成员）
- 干涉标签（目标搜索、收入一位角色、消抹暴露、抹除社会记忆……带修正标价）
- 愿望输入框 → 写成 `【世界调制·提交愿望】` 填进输入框

所以建议：通用壳不带这两个 App；怪谈卡用 adapter 再挂回去。不是「去文案就能通用」——整页都在读写怪谈根。

子宫填充不是这一类。它是角色详情里的一条身体显示：有 `私密档案.子宫填充度` 就画液位，没有就隐藏。按总监裁定，算女性角色通用部件，留在 `ch`。

### 2026-08-27 架构拍板（总监）

- **包体定位**：小手机通用化 = 方便快速把文字卡改造成前端卡的**通用化开源包体**。文档、命名、上手体验按面向外部改造者的标准做。
- **多脚本分职**：每个脚本负责各自的功能，禁止全塞进一个大脚本集成（怪谈 1.0.9 单脚本 392KB 与星月 media_library.js 全家桶均为反例形态）。
- **媒体库拆独立脚本**，媒体数据仓（酒馆助手脚本级变量）**挂媒体库脚本名下**——媒体库本身就是媒体容器 / 图床 URL 地址存储中转，脚本要**明示这个用途**。
- **媒体使用推荐序（分场景，勿混淆）**：
  - **制卡阶段**（用本包把文字卡改造成前端卡、配置媒体资产时）：ST 环境**优先图床 URL**，不推荐媒体库内置媒体——内置是每个玩家都要加载的基础负担，云酒馆与手机部署酒馆容易炸内存；独立前端则无所谓。推荐写在脚本用途注释与开源包文档里，面向制卡者。
  - **游玩中导入**：玩家游玩时通过小手机导入媒体文件没问题，不会导致内存爆炸，**不需要提醒**，游玩 UI 不加任何慎用文案。
