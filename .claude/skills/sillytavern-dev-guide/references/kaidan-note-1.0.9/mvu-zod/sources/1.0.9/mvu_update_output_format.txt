怪谈笔记·绮罗世界 v1.0.3 r3 - [mvu_update]变量输出格式

输出容器:
  - 回复顺序固定为 正文 → 单个 <UpdateVariable>;变量块必须位于回复末尾。
  - 变量块顺序固定为 <UpdateVariable> → <analysis> → </analysis> → <JSONPatch> → JSON数组 → </JSONPatch> → </UpdateVariable>。
  - 禁止在变量块外输出 <analysis>,禁止输出独立变量预分析段。

analysis:
  - 先静默核对生效法则、兑现、业力、修正与杀戮、影响与暴露、新闻与世界联动及其余真实字段。
  - 只概括正文支持的真实变化、结算依据与未结事项,不写路径清单。
  - 有变化时每条结论必须对应至少一个 JSONPatch 操作。
  - 无变化时简述本轮没有受正文支持的变量变化,JSONPatch 输出 [];不要求固定句式。

JSONPatch:
  - 内容必须是合法 JSON 数组;禁止额外文本、Markdown 代码围栏、JSON 注释或尾随逗号。
  - replace 需要 op、path、value;用于任何已存在的完整叶路径。
  - add 需要 op、path、value;用于既有父对象下尚不存在的新字段、既有 record 容器下的全新完整实体或以 /- 追加数组,数组追加前去重。
  - remove 需要 op、path;只删除允许删除的动态 record 项或数组当前索引。
  - move 需要 op、from、path;只用于动态 key 重命名,禁止携带 value。
  - 禁止 add 或 replace 整个固定对象,尤其禁止整块写入 /环境/所在位置、/环境/城市环境、/权限、/暴露调查组。
  - 新增动态 record 时一次 add 完整对象,禁止先建空壳再补字段。
  - 禁止新增顶层根;角色头像、立绘及其变体禁止写入 stat_data。
  - 模型不得通过 JSONPatch 修改既有 /角色档案/*/羁绊标签 或 /角色档案/*/角色类型,包括升格、降级、解除羁绊和直接改写派生值;只有首次完整 add 新角色对象时写入 false/当前互动,后续加入羁绊只由玩家状态栏事务写入。
  - 数字与布尔值使用 JSON 原生类型;true、false 禁止加引号。

path:
  - 顶层根只能是 环境、user、怪谈笔记、权限、影响倾向、暴露调查组、世界演化、舆论新闻、处刑档案、世界调制、角色档案、资产库、居所、载具、雷达系统。
  - path 按斜杠分段后交给 lodash 路径处理,不使用 RFC 6901 的 ~0 或 ~1 转义。
  - 动态 key 禁含 /、.、~、[、],出现时依次改为 ／、．、～、［、］。

格式模板:
<UpdateVariable>
<analysis>
用自然语言列出本轮已确认的变量变化与依据;没有变化时说明没有受正文支持的变化。
</analysis>
<JSONPatch>
[
  {"op":"replace","path":"/<顶层根>/<既有完整叶路径>","value":"<最终值>"},
  {"op":"add","path":"/<顶层根>/<既有父对象>/<新字段或新实体>","value":"<新值或完整对象>"},
  {"op":"remove","path":"/<顶层根>/<动态项或数组当前索引>"},
  {"op":"move","from":"/<顶层根>/<旧动态key>","path":"/<顶层根>/<新动态key>"}
]
</JSONPatch>
</UpdateVariable>
  - 尖括号占位内容必须替换为本轮真实路径和值,禁止原样复制。
  - 只保留本轮实际需要的操作;没有变化时数组直接写 []。

收尾:
  - 没有正文事实支持的变量不更新。
  - JSON 数组结束后必须输出 </JSONPatch>,禁止直接从 ] 跳到 </UpdateVariable>。
