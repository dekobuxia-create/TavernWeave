# 悬浮球（通用组件）

桌宠悬浮球：canvas 自由点阵球（拖拽有数据史莱姆甩尾）+ 拖拽吸附左右边 + 长按切收纳深度 + 半轮盘菜单。点阵球渲染、拖拽手感、半轮盘数学**照抄星月 4.0.0**（3.4.6 沙盘拨定手感 + 3.4.9 灵动化，已验收资产，勿凭感觉改参数）；已裁星月问候气泡与 TA的视角/控制中心/地图键。

## 轮盘（默认 2 键，按拍板删减）

| 键 | 行为 | 目标缺席时 |
|---|---|---|
| 📱 小手机 | 向宿主 window 与 `#ph-statusbar-root` 派发 `ph-orb:open-phone` 事件；小手机 host 接收后确保挂载并闪烁提示 | toast「未检测到小手机」 |
| 🖼️ 气泡头像 | 调 `__phBubble.openManager()` 打开头像气泡管理 | toast「未检测到头像气泡脚本」 |

两个目标脚本都可缺席，球本身照常工作——按需取件。

## 对接契约

- 事件名：`ph-orb:open-phone`（CustomEvent，派发到宿主 window 和小手机根节点）。当前小手机侧的响应是保守语义（确保挂载+根节点闪烁 1.4s）；真机确认小手机 UI 形态后可升级为真正的弹出/展开。
- 头像气泡桥：`__phBubble`（头像气泡脚本挂出）。

## 重建

产物由 `tools/build_orb.mjs` 从 `../星月悬浮球/sources/星月4.0.0/悬浮球与轮盘参考.js` 机械提取组装（前缀替换+键位删减+act 重写+问候气泡剥除），不要手改 `悬浮球.js`——改 build 脚本后重跑：

```powershell
node 怪谈笔记/小手机通用化改造/悬浮球/tools/build_orb.mjs
```

K1 铁律保留：一律 left/top 视口坐标定位（right/bottom 会被 ST 顶层 transform 劫持到长页底端）。
